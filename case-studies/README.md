# Case Studies

> Planned for a later phase; see the [roadmap](../ROADMAP.md). This page describes the intended format.

Analyses of innovation decisions at public companies, using publicly available sources only.

Each case study follows the same structure:

1. **Context** – company, market and timing
2. **The decision** – what was tried and why
3. **Analysis** – through one or more frameworks from [`../frameworks/`](../frameworks/)
4. **Outcome** – what happened, with evidence
5. **Takeaways** – lessons that transfer to other organisations
6. **Sources**
