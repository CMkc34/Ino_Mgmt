# Roadmap

## Phase 1: current project (to 8 December 2026)

Scope, priorities and schedule are defined in the [project charter](docs/project/01-project-charter.md). In short: a trend scan and an opportunity scoring model on one lead theme, built on a shared data pipeline.

## Phase 2: backlog (after Phase 1)

Not committed. Items are picked up after Phase 1 closes, or earlier through change control.

- [ ] Any Should / Could items from Phase 1 that were not delivered (case study, framework write-ups)
- [ ] Portfolio dashboard (moved here from Phase 1 by change request, 2026-11-12)
- [ ] Trend scan: AI in diagnostics / medtech (reusing the pipeline)
- [ ] Trend scan: energy transition technologies (e.g. grid storage, hydrogen)
- [ ] Scheduled monthly refresh of trend data
- [ ] Framework write-ups: Stage-Gate, Jobs-to-be-Done, Lean Startup, Open Innovation, Ambidexterity
- [ ] Second case study in a different sector

## Quality bar for every piece

- Opens with a short summary and ends with a clear **"so what"**: a recommendation or the decision it supports
- Sources cited; assumptions stated
- Reproducible: code and data (or the steps to get the data) included
